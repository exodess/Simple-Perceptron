## Необходимые классы, которые нужно реализовать
![Image](https://external-content.duckduckgo.com/iu/?u=https%3A%2F%2Fvelog.velcdn.com%2Fimages%2Fcneycal%2Fpost%2F6ed694bc-9f27-4895-ad0d-d5aba0dc6633%2Fimage.png&f=1&nofb=1&ipt=748a3b5dab70bb2c4a650e3fb0261ff43e653b70c9714dc876ec1c8262cbb15d)
Вся программа должна быть выстроена в соответствии с паттерном MVC

### Model
- __BaseFileReader__ - базовый класс для классов, которые работают с файлами
- __ImageReader__ - класс, который реализует считывания BMP-изображения и его нормализацию
- __DataReader__ - класс, занимающийся сохранением и загрузкой в/из файла весов перцептрона
- __Neuron__ - класс нейрона как базовой неделимой части, из которой состоит перцептрон
- __Perceptron__ - класс самого перцептрона

### View
- __MainWindow__ - главный класс приложения, управляет отрисовкой интерфейса
- __UserPaintImage__ - класс, который считывает рисунок пользователя, переводит его в BMP-формат и передает в контроллер

### Controller
Контроллер представляет собой прослойку между представлением и внутренней логикой
- __Controller__ - класс, реализующий паттерн Facade - он хранит в себе классы модели, и при пользовательском вводе вызывает необходимый метод определенного класса

## Возможная структура проекта

- **include**
  - **ui** - Описание UI
  - **controller** - Описание контроллера
  - **perceptron** - Описание классов, реализующих перцептрон
  - **tools** - Описание второстепенных классов (Readers)
- **ui**: код приложения
- **controller** - Код контроллера
- **perceptron** - Код классов Neuron и Perceptron
- **tools** - Код классов, отвечающих за работу с файлами
- **CMakeLists.txt** - Сборка через cmake
- **Makefile** - Сборка через make
- **Doxyfile** - Для создания документации через doxygen
- **main.cpp**
